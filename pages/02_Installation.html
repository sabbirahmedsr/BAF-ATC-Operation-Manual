02. Installation

2.1 Application Setup

The simulator is distributed as three separate packages. Please ensure you download and extract the correct package for each respective station:

  • Server Station: BAF ATC Simulator [SERVER] v1.3.21.zip
  • Arrival Station: BAF ATC Simulator [ARRIVAL] v1.3.21.zip
  • Departure Station: BAF ATC Simulator [DEPARTURE] v1.3.21.zip

To extract, right-click the .zip file on the designated station and select Extract All... (or use tools like 7-Zip or WinRAR) to your preferred local directory.

Note: File names and version numbers may change with future updates. Always ensure that the exact same version is installed across all three stations. Additionally, make sure each station runs only its specifically assigned package (Server, Arrival, or Departure) to maintain proper network compatibility.

2.2 Directory Structure

Once extracted, the folder structure for each station should appear as follows. Keep all files in their original locations to prevent runtime errors. We would only require the BAF ATC Simulator.exe from here for further operation.

2.3 Launching the Simulator

To start the application, navigate to the extracted folder and double-click the BAF ATC Simulator.exe file. You can always navigate to the original folder and run the application from here at any time. However, to ease the workflow, it is highly recommended to create a desktop shortcut or Pin the application to your taskbar for quick access.

Note: This application is portable and does not require installation. Simply extract the contents and double-click the BAF ATC Simulator.exe file to launch the simulator directly.

Setting Up Quick Access

To ensure quick access to the simulator, you can create a desktop shortcut or pin the executable to your taskbar.

  • Removing Old Taskbar Shortcuts: If you have a shortcut for an older version already pinned to your taskbar, right-click the existing icon and select Unpin from taskbar.
  • Pinning New Version to Taskbar: Simply drag and drop the new BAF ATC Simulator.exe file directly onto your taskbar to pin it. Then just Single click to launch.
  • Creating Desktop Shortcut: Right-click the BAF ATC Simulator.exe file, then select Send to > Desktop (create shortcut). You can rename the shortcut if u want.
Backup Note: When upgrading, it is strongly recommended to keep your previous working version as a backup. Only replace or delete the older version once you have fully tested and confirmed that the new version is operating correctly.
Note: Ensure that your antivirus or Windows Defender does not block the BAF ATC Simulator.exe, as the simulator requires network permissions to establish communication between the Server and Client stations.
