05. Aircraft Ops

5.1 Aircraft Creation

To add a new aircraft to the simulation, look at the Bottom-left corner of the Client station. You will see a Plus (+) icon, right next to the Options button. Clicking this icon will trigger the CREATE AIRCRAFT popup window. Here, you can set the following details:

  • Category: Choose the type of flight (e.g., Domestic, International, Military, etc.).
  • Call Sign: Select the unique flight ID (e.g., BG367, THAI321, GFN391, ABC668, etc.).
  • Phase Name: Set the current flight phase (e.g., PUSHBACK, ADMIL, Z1, 20 DME, etc.).
  • Gate Name: Select the gate location / number (departures only).
  • Gate Direction: Choose the gate facing direction when available (departures only).

After setting up all parameters, click the CREATE button to spawn the aircraft in the scene.

Note: Each Call Sign is restricted to its specific Category. If you cannot find a specific flight ID, please verify that the correct category is selected, as we often overlook this during operation.

Once created, the aircraft is instantly broadcast across the network, ensuring all stations are updated in real-time. Upon successful synchronization, the following elements are generated instantly as well:

  • Map Node: An Airplane icon in the Map View showing aircraft physical position.
  • Command Node: A Comand Node in the Command Panel for aircraft call & action.
  • Strip Node: A Flight strip in the Strip Panel displaying live telemetry data.

Note: Map Nodes are visible to all stations. However, Strip and Command Nodes are station-specific; Departure stations manage departure aircraft, while Arrival stations manage arrival aircraft.

5.2 Map Node

Every aircraft generates a Map Node, represented by an Airplane Icon, on the Radar or Surface map (or both), to show its physical location. This node features an information box connected by a line, displaying real-time telemetry data exactly where needed. The info box is fully draggable using the left mouse button and includes the following:

  • Callsign: Displays the aircraft identification (e.g., BG 367, BJR 471).
  • Speed & Heading: Shows the current speed in knots (kts) and heading in degrees (°).
  • Altitude: Displays the current altitude in feet (e.g., 4000ft, 3000ft, 1500ft).
  • Close Button (X): Click the cross (X) button at the bottom-right-corner to hide it.
Note: If you hide the aircraft map node and wonder how to get it back, simply click on the aircraft icon itself to make it appear again.

5.3 Command Node Overview

Once you create an aircraft, you can immediately find its Command Node in Command Panel. Its the main control unit for the aircraft with following basic parts:

  • Call Sign: Displays the flight ID for easy identification (top-left).
  • Altitude Setting: A dropdown menu to select the target altitude in the air (top-middle).
  • Movement Button: Confirms/Freeze active aircraft movements (play/pause icon).
  • Additional Tools: Show/Hide additional utility options (three dots).
  • Phase Name: Show/Hide the relevant pilot call list (bottom-left).
  • Next Phase: Switch the next operational path when available (bottom-right).

5.3.1 Aircraft Movement

The system AI primarily manages the aircraft movement, while you use the Movement Button to confirm actions or pause the aircraft. To confirm movmement action or modifying aircraft route follow these operational steps:

  • Approve Movement: When the button shows a Green Play icon, it indicates an action (like Pushback, Taxi, or Line Up) requires your approval. Click the button to confirm when requested by ATC, and the aircraft will follow its predefined path.
  • Freeze Aircraft: Click the Gray Pause icon to instantly freeze the aircraft.
  • Resume Aircraft: Click the Gray Play icon to resume the aircraft back.

When you click the Green Play icon to approve an action, the system handles it in one of two ways:

  • Direct Confirmation: A single click confirms simple commands like Line Up.
  • Confirmation with Parameters: For complex commands, a popup appears to define specific parameters before approval. For example:
    • Pushback: Select the facing direction (e.g., North or South).
    • Taxi: Choose the specific taxi path (e.g., Charlie, Foxtrot, or Victor).

Once you provide the required parameters and confirm, the AI automatically guides the aircraft through its pre-defined movement path.

5.3.2 Next Phase Selection

Located at the bottom-right of the command strip, this indicator shows the aircraft's upcoming phase (e.g., displaying Taxi during Pushback, or Line Up during Taxi). While typically disabled, it becomes an active dropdown whenever multiple next-phase options are possible, for example.

  • During departure before reach up to airborn point, you can decide the aircraft's next path, such as choosing between entering a Circuit or proceeding to a Training Area.
  • During Downwind Before reaching the Base point, set whether the aircraft will perform a Low Go, or a Touch and Go, or a final Landing,.

5.3.3 Pilot Calls

Clicking the Active Phase Name button opens the pilot call list, which appears directly below the button to ensure easy access. This list displays available communications which are relevant to the aircraft's current active phase, making it simple for the operator to find the right option for the current stage of flight.

As illustrated in the above image, these pilot calls are categorized into two distinct types:

  • Direct Call: These are simple call that trigger immediately upon clicking. As you can see in image, Request Pushback does not require any parameters; clicking it will immediately trigger the pilot call.
  • Parametric Call: These are complex call that require additional parameter choice from a Parameter popup window before transmission. As shown in image, a Pushback Approval command requires you to specify a facing direction (e.g., North or South) based on the ATC trainee's command before confirming.
Note: For an effective training session, the operator plays a key role: he/she must trigger the correct pilot call within minimum time when the ATC trainee instructs the pilot. This synchronization will make make the simulation scenario feel alive.
Note: Once a pilot call is played, the text becomes struck-through and turns gray to indicate it has already been used. However, the button remains clickable, allowing you to trigger the same call again if needed.

5.3.4 Altitude Setting

You can adjust the aircraft's target altitude using the Altitude Dropdown located at the top-center of the command strip, which commands the aircraft to climb or descend to the selected flight level (e.g. 6000, 4000, 3000, etc). Remember, This control dropdown only becomes active when the aircraft is in the air; otherwise it remains disabled and labelled as No Action.

5.3.5 Additional Tools

By clicking the three dots option button located at the top-right-corner of the command strip, you can show or hide additional operational tools. These tools include:

  • Repeat Last Call: Replays the previous pilot call.
  • Highlight: Ping a circular wave animation around the aircraft icon on the map.
  • Destroy: Removes the aircraft from the simulation. When clicked, a popup appears requiring you to confirm the action before the aircraft is deleted.

5.4 Strip Node

The Strip Node in the Strip Panel provides a compact summary of each active aircraft. It allows you to monitor critical flight parameters at a glance, as shown below:

  • Callsign: Unique flight identification (e.g., AWA_446).
  • Heading: Current direction in degrees (°).
  • Speed: Current ground speed in knots (kts).
  • Height: Current altitude in feet (e.g., 3000f, 1500ft).
  • Phase Name: Current operational stage (e.g., PUSHBACK, 6DME).
  • Time: Associated timestamp or relevant clock data.
