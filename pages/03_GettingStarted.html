03. Getting Started

3.1 Hardware Startup Sequence

To ensure stable display synchronization, please follow this startup sequence:

  1. Power Up All Devices: Ensure all equipment—including the 3 large TVs, computer stations, and audio/speaker systems—are connected to their power sources and all power switches are turned on.
  2. Turn On Displays: Turn on the three large TV monitors.
  3. Turn On Audio: Power on the speaker system for both left and right channels.
  4. Start Server Station: Power on the central Server computer.
  5. Start Client Stations: Power on the Arrival and Departure Client stations.
Note: Please ensure the three large TV monitors are turned on before starting the Server computer. If they are off, the server computer may fail to detect the correct display output during the boot process.

3.2 Verification Checklist

  • Display Alignment: Ensure all three monitors are active and displaying a seamless visual across all monitors. (If the layout is incorrect, refer to the Troubleshooting section to reconfigure the monitor sequence).
  • Audio Check: Confirm that audio is playing correctly through both the left and right speakers. This is a must to play the Ground Control (Left Channel) and Tower Control (Right Channel) call properly.
  • System Status: Verify that the Server and Client stations have fully initialized and are ready for application launch.

3.3 Launch Application

Single-click the BAF ATC Simulator icon pinned to the taskbar on each machine. After launching the application, follow the steps below to initialize the simulation:

  • Server Station: Once the application opens, click the "Start" button. In the next panel, select the desired airport from the "Airport" dropdown menu and click the "Start" button to load the simulation environment.
  • Client Station: Once the Server Station loads successfully and the application opens on both Arrival and Departure stations, click the "Start" button, select the matching airport from the "Airport" dropdown menu, and click the "Join" button.
Note: Please ensure the Server station has fully initialized the simulation before attempting to join from any Client (Arrival / Departure) station.
Note: You must select the exact same airport on the Client stations as the one chosen on the Server. If the airports do not match, the connection will establish, but the aircraft and map data will display incorrectly or in the wrong locations.

3.4 Closing Application

To safely close the application, follow these steps:

  1. Click the Option button (list icon) at the bottom-left of the screen.
  2. Select Stop Client & Exit and confirm to return to the Home Menu.
  3. Select Exit from the Home Menu and confirm to close the application.
Note: Client stations can join or exit the simulation at any time. However, if the Server station is closed, all active Client sessions will be lost. For a clean shutdown, it is recommended to close the Client stations first, followed by the Server station.
