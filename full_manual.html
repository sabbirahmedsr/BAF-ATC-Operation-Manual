01. Introduction

1.1 System Overview

The BAF ATC Simulator is designed to provide a highly immersive and realistic environment for live, interactive air traffic control training. The system features a comprehensive 180-degree field of view, allowing trainees to monitor a vast portion of the airfield simultaneously, replicating the authentic experience of an actual control tower, as shown below:

1.2 System Architecture

The simulator operates as a distributed multi-node network, featuring three primary stations integrated with a 180-degree Panoramic Trio View designed to replicate actual airport tower view.

  • Server Station: Acts as the central hub, managing the live 180-degree scenario, environmental conditions, and weather control systems.
  • Arrival Station: Functions as a client node for real-time monitoring of arrival traffic, executing pseudo-pilot control commands, and triggering pre-recorded pilot voice communications.
  • Departure Station: Functions as a client node for real-time monitoring of departure traffic, executing pseudo-pilot control commands, and triggering pre-recorded pilot voice communications.
  • Panoramic Trio View: Consists of three large-scale high-definition displays connected to the server, which provide a seamless, panoramic 180-degree view that replicates the immersive perspective of an actual airport control tower.

1.3 Operational Airfield Scenarios

The simulator currently features two high-fidelity airport environments, with support for integrated day/night cycles and dynamic weather systems (e.g., fog, storms, and atmospheric effects like rainbows).

1.4 Training Philosophy

This simulator focuses on live, hands-on training to bridge the gap between theoretical knowledge and operational reality. By providing a highly interactive scenario-based environment, the system allows ATC students to practice real-world decision-making. Trainees can engage directly with the simulator, managing dynamic traffic situations and airport operations in a controlled yet authentic setting.

  • Hands-on Experience: Practical engagement with ATC systems.
  • Interactive Scenarios: Dynamic environments that mimic real-life challenges.
  • Operational Readiness: Focused training to ensure students are prepared for actual air traffic control responsibilities.

02. Installation

2.1 Application Setup

The simulator is distributed as three separate packages. Please ensure you download and extract the correct package for each respective station:

  • Server Station: BAF ATC Simulator [SERVER] v1.3.21.zip
  • Arrival Station: BAF ATC Simulator [ARRIVAL] v1.3.21.zip
  • Departure Station: BAF ATC Simulator [DEPARTURE] v1.3.21.zip

To extract, right-click the .zip file on the designated station and select Extract All... (or use tools like 7-Zip or WinRAR) to your preferred local directory.

Note: File names and version numbers may change with future updates. Always ensure that the exact same version is installed across all three stations. Additionally, make sure each station runs only its specifically assigned package (Server, Arrival, or Departure) to maintain proper network compatibility.

2.2 Directory Structure

Once extracted, the folder structure for each station should appear as follows. Keep all files in their original locations to prevent runtime errors. We would only require the BAF ATC Simulator.exe from here for further operation.

2.3 Launching the Simulator

To start the application, navigate to the extracted folder and double-click the BAF ATC Simulator.exe file. You can always navigate to the original folder and run the application from here at any time. However, to ease the workflow, it is highly recommended to create a desktop shortcut or Pin the application to your taskbar for quick access.

Note: This application is portable and does not require installation. Simply extract the contents and double-click the BAF ATC Simulator.exe file to launch the simulator directly.

Setting Up Quick Access

To ensure quick access to the simulator, you can create a desktop shortcut or pin the executable to your taskbar.

  • Removing Old Taskbar Shortcuts: If you have a shortcut for an older version already pinned to your taskbar, right-click the existing icon and select Unpin from taskbar.
  • Pinning New Version to Taskbar: Simply drag and drop the new BAF ATC Simulator.exe file directly onto your taskbar to pin it. Then just Single click to launch.
  • Creating Desktop Shortcut: Right-click the BAF ATC Simulator.exe file, then select Send to > Desktop (create shortcut). You can rename the shortcut if u want.
Backup Note: When upgrading, it is strongly recommended to keep your previous working version as a backup. Only replace or delete the older version once you have fully tested and confirmed that the new version is operating correctly.
Note: Ensure that your antivirus or Windows Defender does not block the BAF ATC Simulator.exe, as the simulator requires network permissions to establish communication between the Server and Client stations.

03. Getting Started

3.1 Hardware Startup Sequence

To ensure stable display synchronization, please follow this startup sequence:

  1. Power Up All Devices: Ensure all equipment—including the 3 large TVs, computer stations, and audio/speaker systems—are connected to their power sources and all power switches are turned on.
  2. Turn On Displays: Turn on the three large TV monitors.
  3. Turn On Audio: Power on the speaker system for both left and right channels.
  4. Start Server Station: Power on the central Server computer.
  5. Start Client Stations: Power on the Arrival and Departure Client stations.
Note: Please ensure the three large TV monitors are turned on before starting the Server computer. If they are off, the server computer may fail to detect the correct display output during the boot process.

3.2 Verification Checklist

  • Display Alignment: Ensure all three monitors are active and displaying a seamless visual across all monitors. (If the layout is incorrect, refer to the Troubleshooting section to reconfigure the monitor sequence).
  • Audio Check: Confirm that audio is playing correctly through both the left and right speakers. This is a must to play the Ground Control (Left Channel) and Tower Control (Right Channel) call properly.
  • System Status: Verify that the Server and Client stations have fully initialized and are ready for application launch.

3.3 Launch Application

Single-click the BAF ATC Simulator icon pinned to the taskbar on each machine. After launching the application, follow the steps below to initialize the simulation:

  • Server Station: Once the application opens, click the "Start" button. In the next panel, select the desired airport from the "Airport" dropdown menu and click the "Start" button to load the simulation environment.
  • Client Station: Once the Server Station loads successfully and the application opens on both Arrival and Departure stations, click the "Start" button, select the matching airport from the "Airport" dropdown menu, and click the "Join" button.
Note: Please ensure the Server station has fully initialized the simulation before attempting to join from any Client (Arrival / Departure) station.
Note: You must select the exact same airport on the Client stations as the one chosen on the Server. If the airports do not match, the connection will establish, but the aircraft and map data will display incorrectly or in the wrong locations.

3.4 Closing Application

To safely close the application, follow these steps:

  1. Click the Option button (list icon) at the bottom-left of the screen.
  2. Select Stop Client & Exit and confirm to return to the Home Menu.
  3. Select Exit from the Home Menu and confirm to close the application.
Note: Client stations can join or exit the simulation at any time. However, if the Server station is closed, all active Client sessions will be lost. For a clean shutdown, it is recommended to close the Client stations first, followed by the Server station.

04. Interface

The simulator interface is designed to be simple and organized. It is divided into various sections to facilitate smooth interaction and inspection. Every panel displays its Name at the Top-Left Corner for quick identification. The main panels include the Radar Map and Surface Map, the Info Panel, the Console (Server only), and the Strip Panel(Client only) and Command Panel (Client only).

4.1 Radar & Surface Map Panels

The map panels are the central part of the interface, providing essential tactical data for air traffic control.

  • Radar Map: Located on the Left Side, half of the screen, provides a comprehensive TMA view, from 12NM up to 50NM (when available), essential for tracking aircraft positions, identifying navigation aids, and monitoring flight paths within the approach and departure corridors.
  • Surface Map: Positioned on the Bottom-Right, occupies half of the vertical and horizontal area. It provides a detailed airfield layout, allowing operators to visualize taxiways, runways, and parking areas to manage ground movements effectively.

Both panels feature two critical control dropdowns at the top-right corner to customize your view:

  • Theme: Toggle between [NONE], [LIGHT], [DARK], or [S-MAP (SATELLITE)] modes.
  • Range/View: Dynamic controls based on the map type:
    • Radar Map: Adjust the radar range (e.g., 50NM, 25NM, 12NM) for required coverage.
    • Surface Map: Toggle between specific ground views like Runway or Parking.

4.2 Information Panel

Located at the Top-Middle of the screen, this panel displays essential real-time data and scoring for all stations. It tracks ATC Time, Elapsed Time, and Date. Additionally, the Server shows total Arrival/Departure scores, while the Client shows station-specific performance metrics.

  • Data Display: It tracks the current ATC Time, Elapsed Time, and Date. These metrics are vital for pilots to coordinate activities such as startup requests or taxi timing.
  • Performance Metrics:
    • Server View: Displays total system Arrival and Departure scores for overall monitoring.
    • Client View: Displays performance scores specific to the assigned station's role.

4.3 Console Panel (Server Only)

Located on the Top-Right, this panel is the central monitoring hub for the Server. This is exclusive to the Server station for system-wide monitoring.

  • Event Logging: This section continuously lists system activities, such as network updates, aircraft spawning, and flight data management.
  • Connection Status: Located at the top, two circular indicators show real-time client connectivity. [GRAY] means disconnected, while [GREEN] confirms an active connection.

4.4 Strip & Command Panels (Client Only)

Located on the Right Side of the screen, these panels are exclusive to the Client station for managing active flight operations.

  • Strip Panel: Positioned in the Center-Right area (below the Info Panel), this panel displays electronic flight strips for all active aircraft, providing a quick summary of essential flight information and status updates.
  • Command Panel: Positioned at the Top-Right, this is the main interaction hub. It allows you to send instructions to aircraft, including movement confirmations with parameters, playing pre-recorded pilot calls, adjusting height, deleting flights, pausing tasks, and highlighting specific targets for monitoring.

4.5 Options Menu

Located at the Bottom-Left, look alike a List Icon, provides access to essential system tools:

  • General: Application exit and configuration.
  • Server-Only: Controls for Global Pause, Weather setup, and traffic Sequence loading.
  • Speed Control: A slider at the bottom adjusts the global simulation speed.
Note: The current simulation speed is displayed in the Info Panel. If the speed is set to anything other than 1x, the indicator highlights with a Red Background to warn the operator.
Note: If the simulation appears frozen or aircraft are not moving, always check if the Global Pause is active. It is common to overlook this, so ensure the system is not paused before troubleshooting other issues.

05. Aircraft Ops

5.1 Aircraft Creation

To add a new aircraft to the simulation, look at the Bottom-left corner of the Client station. You will see a Plus (+) icon, right next to the Options button. Clicking this icon will trigger the CREATE AIRCRAFT popup window. Here, you can set the following details:

  • Category: Choose the type of flight (e.g., Domestic, International, Military, etc.).
  • Call Sign: Select the unique flight ID (e.g., BG367, THAI321, GFN391, ABC668, etc.).
  • Phase Name: Set the current flight phase (e.g., PUSHBACK, ADMIL, Z1, 20 DME, etc.).
  • Gate Name: Select the gate location / number (departures only).
  • Gate Direction: Choose the gate facing direction when available (departures only).

After setting up all parameters, click the CREATE button to spawn the aircraft in the scene.

Note: Each Call Sign is restricted to its specific Category. If you cannot find a specific flight ID, please verify that the correct category is selected, as we often overlook this during operation.

Once created, the aircraft is instantly broadcast across the network, ensuring all stations are updated in real-time. Upon successful synchronization, the following elements are generated instantly as well:

  • Map Node: An Airplane icon in the Map View showing aircraft physical position.
  • Command Node: A Comand Node in the Command Panel for aircraft call & action.
  • Strip Node: A Flight strip in the Strip Panel displaying live telemetry data.

Note: Map Nodes are visible to all stations. However, Strip and Command Nodes are station-specific; Departure stations manage departure aircraft, while Arrival stations manage arrival aircraft.

5.2 Map Node

Every aircraft generates a Map Node, represented by an Airplane Icon, on the Radar or Surface map (or both), to show its physical location. This node features an information box connected by a line, displaying real-time telemetry data exactly where needed. The info box is fully draggable using the left mouse button and includes the following:

  • Callsign: Displays the aircraft identification (e.g., BG 367, BJR 471).
  • Speed & Heading: Shows the current speed in knots (kts) and heading in degrees (°).
  • Altitude: Displays the current altitude in feet (e.g., 4000ft, 3000ft, 1500ft).
  • Close Button (X): Click the cross (X) button at the bottom-right-corner to hide it.
Note: If you hide the aircraft map node and wonder how to get it back, simply click on the aircraft icon itself to make it appear again.

5.3 Command Node Overview

Once you create an aircraft, you can immediately find its Command Node in Command Panel. Its the main control unit for the aircraft with following basic parts:

  • Call Sign: Displays the flight ID for easy identification (top-left).
  • Altitude Setting: A dropdown menu to select the target altitude in the air (top-middle).
  • Movement Button: Confirms/Freeze active aircraft movements (play/pause icon).
  • Additional Tools: Show/Hide additional utility options (three dots).
  • Phase Name: Show/Hide the relevant pilot call list (bottom-left).
  • Next Phase: Switch the next operational path when available (bottom-right).

5.3.1 Aircraft Movement

The system AI primarily manages the aircraft movement, while you use the Movement Button to confirm actions or pause the aircraft. To confirm movmement action or modifying aircraft route follow these operational steps:

  • Approve Movement: When the button shows a Green Play icon, it indicates an action (like Pushback, Taxi, or Line Up) requires your approval. Click the button to confirm when requested by ATC, and the aircraft will follow its predefined path.
  • Freeze Aircraft: Click the Gray Pause icon to instantly freeze the aircraft.
  • Resume Aircraft: Click the Gray Play icon to resume the aircraft back.

When you click the Green Play icon to approve an action, the system handles it in one of two ways:

  • Direct Confirmation: A single click confirms simple commands like Line Up.
  • Confirmation with Parameters: For complex commands, a popup appears to define specific parameters before approval. For example:
    • Pushback: Select the facing direction (e.g., North or South).
    • Taxi: Choose the specific taxi path (e.g., Charlie, Foxtrot, or Victor).

Once you provide the required parameters and confirm, the AI automatically guides the aircraft through its pre-defined movement path.

5.3.2 Next Phase Selection

Located at the bottom-right of the command strip, this indicator shows the aircraft's upcoming phase (e.g., displaying Taxi during Pushback, or Line Up during Taxi). While typically disabled, it becomes an active dropdown whenever multiple next-phase options are possible, for example.

  • During departure before reach up to airborn point, you can decide the aircraft's next path, such as choosing between entering a Circuit or proceeding to a Training Area.
  • During Downwind Before reaching the Base point, set whether the aircraft will perform a Low Go, or a Touch and Go, or a final Landing,.

5.3.3 Pilot Calls

Clicking the Active Phase Name button opens the pilot call list, which appears directly below the button to ensure easy access. This list displays available communications which are relevant to the aircraft's current active phase, making it simple for the operator to find the right option for the current stage of flight.

As illustrated in the above image, these pilot calls are categorized into two distinct types:

  • Direct Call: These are simple call that trigger immediately upon clicking. As you can see in image, Request Pushback does not require any parameters; clicking it will immediately trigger the pilot call.
  • Parametric Call: These are complex call that require additional parameter choice from a Parameter popup window before transmission. As shown in image, a Pushback Approval command requires you to specify a facing direction (e.g., North or South) based on the ATC trainee's command before confirming.
Note: For an effective training session, the operator plays a key role: he/she must trigger the correct pilot call within minimum time when the ATC trainee instructs the pilot. This synchronization will make make the simulation scenario feel alive.
Note: Once a pilot call is played, the text becomes struck-through and turns gray to indicate it has already been used. However, the button remains clickable, allowing you to trigger the same call again if needed.

5.3.4 Altitude Setting

You can adjust the aircraft's target altitude using the Altitude Dropdown located at the top-center of the command strip, which commands the aircraft to climb or descend to the selected flight level (e.g. 6000, 4000, 3000, etc). Remember, This control dropdown only becomes active when the aircraft is in the air; otherwise it remains disabled and labelled as No Action.

5.3.5 Additional Tools

By clicking the three dots option button located at the top-right-corner of the command strip, you can show or hide additional operational tools. These tools include:

  • Repeat Last Call: Replays the previous pilot call.
  • Highlight: Ping a circular wave animation around the aircraft icon on the map.
  • Destroy: Removes the aircraft from the simulation. When clicked, a popup appears requiring you to confirm the action before the aircraft is deleted.

5.4 Strip Node

The Strip Node in the Strip Panel provides a compact summary of each active aircraft. It allows you to monitor critical flight parameters at a glance, as shown below:

  • Callsign: Unique flight identification (e.g., AWA_446).
  • Heading: Current direction in degrees (°).
  • Speed: Current ground speed in knots (kts).
  • Height: Current altitude in feet (e.g., 3000f, 1500ft).
  • Phase Name: Current operational stage (e.g., PUSHBACK, 6DME).
  • Time: Associated timestamp or relevant clock data.

06. Weather & Time

The ATC Simulator integrates a highly sophisticated, procedural sky and weather system. This architecture enables real-time atmospheric manipulation, delivering a deeply immersive environment. The following illustration depicts a typical foggy day, which creates an exceptaional challenging situation for an ATC with low visibility, demonstrating the system's dynamic rendering capabilities.

To access the environmental controls, navigate to the Sky and Weather panel via the options menu (located at the bottom-left corner of the interface, indicated by a list icon), or simply utilize the keyboard shortcut Ctrl + W.

Note: If you find the extensive settings overwhelming, it is always recommended to select a pre-configured weather profile for a quick and consistent setup.

6.1 Weather Profiles (Presets)

For rapid configuration, the simulator includes ten pre-configured weather profiles. You can easily select these from the "Weather Profile" dropdown menu, located at the top section of the Sky and Weather control popup. A short description of each is as follows:

  • Default: Standard atmospheric conditions for routine training.
  • Sunny Day: Clear skies with optimal visibility.
  • Cloudy Day: Partially overcast skies with light cloud coverage.
  • Overcast: Dense cloud coverage reducing overall brightness.
  • Rainy Day: Moderate rainfall with associated atmospheric effects.
  • Storm: Intense weather with heavy rain, low visibility, and lightning.
  • Dark Night: Standard night environment with minimal ambient light.
  • Moonlit Night: Night operation with significant illumination from the moon.
  • Foggy: Low visibility conditions simulating ground-level mist.
  • Rainbow: A specialized post-rain visual effect.
  • Aurora: An experimental atmospheric effect for visual variety.

6.2 Custom Settings (Advanced)

For advanced users requiring specific training environments, the system offers granular control over time, location, and atmospheric parameters. These settings are categorized within the Sky and Weather control interface.

Time and Location

This module allows for precise calibration of the simulation's temporal and geographical state. Specially you can set Day/Night mode from here using Hour of day slider.

  • Month of Year: Sets the calendar month to adjust seasonal lighting and environment.
  • Day of Month: Defines the specific day to adjust sun positioning and lunar cycles.
  • Hour of Day: Manually selects the time to simulate dawn, daylight, dusk, or night.
  • Auto Change Speed: Controls the progression rate of the dynamic time system.
  • Latitude & Longitude: Sets the precise geographical coordinates of the airport.
  • Orientation: Rotates the global celestial direction to match runway headings.
Tip: Use the Auto Change Speed slider to create dynamic, time-lapse scenarios that test a trainee's adaptability to changing light conditions.

Cloud Setting

This section provides comprehensive control over cloud formations, density, and movement to realistically simulate various sky conditions.

Basic Cloud
  • Alto Stratus Amount: Adjusts the density and coverage of mid-level stratus clouds.
  • Cirrus Amount: Controls the visibility and spread of high-altitude wispy clouds.
  • Cumulus Amount: Defines the quantity and prominence of puffy, low-level clouds.
  • Cloud Scale: Sets the overall size and uniformity of the cloud formations.
Cumulus Parameter
  • Quality: Determines the rendering fidelity and sharpness of cumulus clouds.
  • Details: Adjusts the structural complexity and graininess of cloud textures.
  • Frequency: Sets the occurrence rate of cloud patches across the sky.
  • Speed: Controls the velocity at which clouds drift across the horizon.
  • Direction: Defines the movement heading of the clouds to match wind flow.

The following visualization demonstrates the system's dynamic rendering capabilities, showcasing a realistic cloudscape achieved through precise adjustments of the Basic Cloud and Cumulus Parameter settings.

Weather Setting

This module provides control over atmospheric conditions, allowing for the simulation of diverse meteorological scenarios to challenge ATC operations.

  • Fog Density: Adjusts the thickness of ground-level mist to limit visual range.
  • Humidity: Sets the moisture level in the air affecting atmospheric clarity.
  • Temperature: Defines the ambient thermal state, influencing overall weather behavior.
  • Overcast Amount: Sets the intensity of cloud cover obscuring direct sunlight.
  • Rain Amount: Controls the volume and intensity of rainfall.
  • Lightning: Adjusts the frequency and intensity of lightning strikes during storms.
  • Snow Amount: Sets the volume and accumulation intensity of snowfall.
  • Rainbow: Toggles the intensity of the rainbow effect post-precipitation.
  • Wind Amount: Controls the velocity and strength of wind gusts across the airfield.
Note: Some parameters may overlap on other parameter. For example, setting Overcast Amount to its maximum will fully cover the sky, so you can not see any changes made on Cumulus or Cirrus setting.

Sound Setting

This section allows users to balance the audio output of the simulation, ensuring optimal clarity for training exercises as shown in image_16377d.png.

  • Master Volume: Adjusts the global audio output level for the entire simulation.
  • Wind Volume: Controls the intensity of ambient wind audio effects.
  • Day Volume: Sets the background sound levels for daytime environment presets.
  • Night Volume: Defines the volume level for nighttime ambient soundscapes.
  • Rain Volume: Adjusts the audio prominence of precipitation effects.
  • Thunder Volume: Controls the impact and volume of storm-related thunder sounds.

More Parameter

This section provides advanced lighting adjustments to fine-tune the visual environment.

  • Day Sky Light: Adjusts the brightness of the sky during daytime.
  • Day Surface Light: Controls the intensity of ground surface light during the day.
  • Night Sky Light: Modifies the luminosity of the sky during nighttime.
  • Night Surface Light: Regulates the brightness of ground surfaces during night.

6.3 Additional Controls

At the bottom of the popup, additional utility functions are available to manage the environment:

  • Light : ON/OFF: Toggles the simulation's artificial lighting systems.
  • Random: Generates a randomized weather profile for unpredictable training scenarios.
  • Reset All: Reverts all atmospheric settings to the system default.
  • Back: Closes the weather popup and returns to the previous menu.
Note: Since the system is procedural and runtime-based, changes made to custom settings will take effect immediately without requiring a restart of the simulation.

6.4 Day/Night Operation

Users can manage time and lighting conditions through two primary methods:

  • Weather Presets: Quickly select scenarios like Dark Night or Moonlit Night for instant environmental changes. For twist, Stormy Day also make the light as dark as night.
  • Custom Settings (Advanced): Use the Time and Location module in the Sky and Weather interface, where the Hour of Day slider allows manual transitions between dawn, daylight, dusk, and night cycles.

07. Special Showcase

7.1 Special Sequence (Exercise Scenario)

This module provides pre-configured scenarios for professional demonstrations, specifically designed for Air Force Chief presentations. These scenarios require a specially trained operator and precise timing for perfect synchronization.

How to Load the Scenario

To begin, navigate to the bottom-left Option Menu and click the Load Sequence button. This action will automatically clear all existing aircraft from the scene and instantly spawn a new set of scenario-ready units. Once loaded, you can manage these aircraft through arrival and departure stations just like standard aircraft control.

Sequence Calls

Within the same Option Menu, clicking Sequence Call or (Ctrl+W) opens a specialized window containing additional voice commands tailored for these scenarios. You can play these audio clips instantly by clicking any item from the pilot call list, functioning exactly like the standard pilot call buttons found in the main command node.

7.2 Airport Vehicles & Ground Operations

This module lets you control three essential ground vehicles at VGHS airport: Inspection, Dragchute, and CAAB vehicles. You can easily activate, pause, or resume any of these at any time using the following keyboard shortcuts.

Keyboard Shortcuts & Controls

  • Inspection Vehicle: Press I or Numpad 1 to Activate & then Pause/Resume.
  • Dragchute Vehicle: Press D or Numpad 2 to Activate & then Pause/Resume.
  • CAAB Vehicle: Press C or Numpad 3 to Activate & then Pause/Resume.
Note: Quickly pressing the assigned key (e.g. I or D or C) multiple times will Delete/Remove the vehicle from the scene.

9.1 System Verification Checklist

While our support team is always available to assist you, we encourage you to perform these quick checks first if you encounter any irregularities. Although these steps seem very simple, we often overlook or accidentally miss these basic details during operation. Verifying these common points can quickly resolve many issues or at least make the system ready for the next stage even before you need professional assistance.

  • Power: Check that all power switches are turned on.
  • Cables: Make sure all video, controller, and device cables are plugged in firmly.
  • Sound: Verify speakers are connected and the volume is not muted from any point.
  • Network: Ensure the network cable is connected and the network switch is powered on.
  • MASTER CHECK: Confirm that all hardware and peripherals are functioning correctly within the operating system before launching our software.
  • System: Ensure the server computer is running and the software is launched.
Note: While it may seem simple, but Restart often works like magic. If you encounter any unexpected issues, we highly recommend powering off the entire system completely, waiting for a while, and then performing a fresh restart. This simple step often resolves most common irregularities before you even need to call for support.

9.2 Common Troubleshooting

After verifying the system checklist, if you still encounter any irregularities, do not worry—you are already familiar with the setup and can often resolve these minor issues yourself. While the following steps are not guaranteed "fixes" for every scenario, they are effective workarounds that resolve most common hiccups. Give them a try first, and if the problem persists, our support team is always here to provide expert assistance.

1. Any or all of 3 Large TVs showing "No Signal" or `No HDMI output`

Likely Cause: The system failed to detect the display, often because the TV was turned off during the server boot process.

Corrective Action: Perform a full power cycle. Completely shut down the entire system, wait for a while, and then power on the TVs first. Once all screens are active, boot the server computer again.

2. Mis-arrangement of Screen Layout (Panoramic view looks scrambled)

Likely Cause: Our software and system require the monitors to be connected in a very specific order. This issue occurs if the display configuration has been reset, the cables were swapped, or the system misidentified the display sequence during startup.

Corrective Action: Right-click on your desktop and select Display Settings. Scroll down to the Multiple displays section and click the Identify button. This will display a large number on each screen so you can verify the current order (Standard monitor should be 1, and the 180° panorama TVs should be 2, 3, and 4 respectively). If the order is incorrect, shuffle the HDMI cables at the back of the server pc to match the required sequence. Restart the system once finished to ensure the software re-detects the correct layout.

Note: Since Windows does not always assign a fixed port-to-output index, shuffling cables can be a trial-and-error process. Adding or moving a cable may sometimes change the display number unexpectedly, so you may need to repeat the Identify process until the sequence is correctly aligned.

Tips: Instead of changing HDMI cables, sometimes switching the 3 TVs physical position might be a faster way to achieve the correct order.

3. Simulator Application Fails to Launch

Likely Cause: The source files might have been moved, renamed, or deleted from the original directory. As this is a Unity-based build, the application requires all supporting files to remain in their original location to function.

Corrective Action: Verify the original installation folder to ensure all components are present, as listed in the Directory Structure (Section 2.2). Check that the BAF ATC Simulator_Data folder and all core files (such as UnityPlayer.dll) are intact. If the structure has been altered, move the files back to their original path. Finally, launch the application as an administrator directly from the BAF ATC Simulator.exe file.

Note: If the issue persists, the best practice is to extract the original zip file again into a new folder to ensure a fresh installation and resolve any potential file corruption or path errors. That is why, we always recommend you that you never lose or delete the original zip file, even if the system is working perfectly.

4. Graphical Lag or Stuttering

Likely Cause: This is often caused by the GPU overheating during long hours of operation, or outdated graphics drivers failing to handle the rendering load.

Corrective Action: Ensure the server environment has proper ventilation to prevent the GPU from overheating. Update your graphics drivers to the latest version and verify that the Power Management Mode is set to "High Performance." In the simulator's main settings menu, locate the Quality dropdown and switch to a lower quality level to stabilize the frame rate.

5. Airplane or Map Misplacement

Likely Cause: This occurs if the server station and the client stations are loaded with different airport maps (e.g., one is running VGHS while another is on VGJR).

Corrective Action: Before starting your session, ensure that every connected station (both server and all clients) has selected and loaded the exact same airport map. If the airplane appears misplaced, stop the simulation, confirm that everyone is on the same airport, and restart the session to ensure proper synchronization.

6. Audio Output Issues

Likely Cause: The issue may arise from incorrect sound device selection in the operating system, a muted channel, or a loose connection in the audio interface.

Corrective Action: Ensure the system volume is not muted at any point. Select the correct output device in Windows Sound settings. If audio is still missing, check the physical connections between the server and the audio interface.

Note: Our system uses the left and right audio channels separately. To ensure both are working correctly, please play a "Left/Right Speaker Test" audio (available on YouTube / or from anywhere) to verify that your audio interface and cables are working properly, without even lanching our software.

7. Pilot Call Is Not Playing

Likely Cause: The specific audio data might be missing from the files. However, this is a critical component and should never happen under normal operation.

Corrective Action: First, ensure that your audio output is working properly by following the steps in Section 6. If the audio is confirmed to be working but the pilot call still fails to play, please document the issue by noting the call sign, the flight phase (e.g., taxi, departure, arrival), and the specific audio message that is missing. If possible, capture a screenshot of the simulation state when the error occurred and share these details with the development team for analysis.

Still facing issues? If the issue is not yet resolved or you encounter any complex scenario, do not hesitate to contact our technical support line. We are here to help!

9.3 The Hidden Problem Solver Hero

We haven’t just delivered the software and walked away; we are with you every step of the way. Our system operates as a silent sentinel in the background, constantly monitoring performance to ensure everything runs smoothly. Most of the time, you won’t even know it’s there.

However, in the rare event that an error occurs, our hidden "hero"—the In-Game Debug Console—will instantly appear. We genuinely hope you never have to encounter it, but if a glitch happens, this console is your direct line to a quick resolution.

System Workflow:

  1. Detection: The system detects an operational error.
  2. Alert: The small, red "Problem Solver Icon" (visible on the right side of the diagram) appears on the screen, indicating a critical issue.
  3. Expansion: Clicking this small "Problem Solver Icon" expands the full In-Game Debug Console across the screen. This large view displays detailed technical logs, allowing you to view and, if necessary, copy specific troubleshooting details.

How to use it if an issue arises:

  • Capture the Issue: If the In-Game Debug Console pops up or is expanded, please take a screenshot of the entire view, including the detailed log messages.
  • Copy the Reason: We have made it simple to copy the exact error message text directly from the logs. Copying this text is crucial for us, as it contains the technical "DNA" of the problem.
  • Notify Us: Send the screenshot and the copied error details to our support team, and we will deal the rest within a very short time.
